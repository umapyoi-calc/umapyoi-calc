8) CRITICAL GOTCHAS DISCOVERED DURING THIS SESSION
- Running commands in workspace parent folder (instead of umapyoi-calc/) causes npm/firebase context errors.
- firebase use fails with:
  - "firebase use must be run from a Firebase project directory"
  when firebase init not done in that folder.
- firebase projects:list can fail with 401 when CLI token is stale.
  Fix: firebase logout + firebase login --reauth
- Using wrong bucket name causes:
  - "The specified bucket does not exist."
  Correct bucket used in this project: umapyoi-calc-dev.firebasestorage.app
- During interactive firebase init hosting, wrong project can be selected by mistake.
  Always verify .firebaserc default project after init.

9) SECURITY NOTES
- Never commit service account key JSON files.
- Never commit .env.local.
- Service account is only for admin scripts (upload/seed), never for frontend browser code.
- If a key leaks, rotate/revoke immediately in Firebase console.
